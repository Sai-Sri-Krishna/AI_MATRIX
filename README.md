# 🌌 Ai_Matrix: Future-Lodging & AI Discovery

An interactive, high-performance web platform designed for the next generation of travelers. This project combines a futuristic "Matrix" aesthetic with AI-driven discovery tools to redefine how users explore boutique stays and lodging.

## ✨ Features
- **AI Mood Radar:** An interactive visualization that maps user travel preferences to specific lodging vibes in real-time.
- **Dynamic Boutique Carousel:** A smooth, JavaScript-driven horizontal slider showcasing curated stays with high-fidelity imagery.
- **Particle System Background:** A high-performance HTML5 Canvas animation creating a futuristic, immersive environment.
- **Responsive "Staybnb" Layout:** A mobile-first, glassmorphic design optimized for seamless discovery across all devices.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Custom Variables & Modern Layouts)
- **Logic:** JavaScript (Vanilla ES6+)
- **Graphics:** HTML5 Canvas API for particle effects
- **Design:** Modern UI/UX with Glassmorphism and pulsing state indicators

## 🕹️ How It Works
1. **Interactive Discovery:** The system uses a `boutique-carousel` container where JavaScript dynamically injects boutique data.
2. **Mood Analysis:** The platform interprets user interaction to shift the UI state, adjusting colors and recommendations.
3. **Immersive Environment:** A dedicated particle system runs in the background, responding to the futuristic theme of the "Ai_Matrix."
